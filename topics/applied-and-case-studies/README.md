# Topic — Applied & Case Studies

What happened when someone actually shipped it. Post-mortems, migration stories, adoption reports, and
domain-specific deployments — the material that keeps the rest of this repo honest.

**In scope:** production deployment write-ups, before/after numbers, organisational adoption patterns,
domain applications (engineering, support, finance, operations), security and compliance experience,
failure post-mortems, build-vs-buy decisions.

**Out of scope:** technique explained in the abstract — that belongs in whichever topic owns the
technique. An entry lands here when the story *is* the deployment.
